# Безопасность

Код ученика исполняется только в браузере, в Pyodide. Фильтр обычного import не пускает os, subprocess, socket, ctypes, js и другие модули из списка и останавливается по таймеру. Это учебное ограничение, а не граница безопасности: код работает на компьютере ученика. Проверка материалов идёт системным Python и не пропускает вызовы вне общего с Pyodide набора. Подозрительные события пишутся в таблицу security_events без текста программы. Пароли хранятся как хеш. Код сброса пароля возвращается в ответе только при DFP_ENV=development.
