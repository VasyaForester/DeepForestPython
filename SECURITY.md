# Безопасность

Код ученика исполняется только в браузере. Worker запрещает импорт os, subprocess, socket, ctypes, js и останавливается по таймеру. Подозрительные события пишутся в таблицу security_events без текста программы. Пароли хранятся как хеш. Код сброса пароля возвращается в ответе только при DFP_ENV=development.
