# Программа Python

Один курс для разработки и анализа данных. Задания различаются контекстом, а не отдельным треком. Сейчас написаны первые три урока раздела 1. Остальные разделы стоят в карте как план.

1. Старт и основы Python. Как устроено программирование, print, строки, комментарии, переменные, int и float, bool и None, арифметика, сравнения, логика, input, f-строки. Опубликованы: первый код, переменные, ввод и типы.
2. Условия и циклы. if, else, elif, вложенность, while, for, range, break и continue.
3. Строки и коллекции. Индексы, срезы, методы строк, list, tuple, set, dict, распаковка, comprehensions.
4. Функции. def, параметры, return, аргументы, значения по умолчанию, область видимости, args, рекурсия.
5. Файлы, данные и модули. Файлы, кодировки, pathlib, CSV, JSON, даты, random, import.
6. Бонус: командная строка. Терминал, навигация, файлы, запуск Python.
7. Исключения, отладка и тестирование. Traceback, try/except, raise, assert, pytest.
8. ООП. Классы, наследование, свойства, dunder-методы, dataclasses.
9. Алгоритмы и структуры данных. Сложность, поиск, сортировки, стек, очередь, деревья, графы.
10. Python глубже. Итераторы, генераторы, замыкания, декораторы, itertools, match.
11. Окружение и пакеты. python -m, venv, pip, pyproject, переменные окружения, начало Git.
12. Git и GitHub. Remote, pull request, конфликты, Actions.
13. HTTP, Web и API. URL, методы, коды, JSON, разбор ответов.
14. SQL. SELECT, JOIN, CTE, оконные функции, транзакции, SQLAlchemy.
15. NumPy и Pandas. Массивы, векторизация, DataFrame, пропуски, очистка.
16. Визуализация и статистика. Графики, распределения, корреляция, проверка гипотез.
17. Производительность. timeit, память, потоки, GIL, multiprocessing, asyncio. Часть тем потребует локальный Python.
18. Backend. Flask, REST, FastAPI, Pydantic, тесты API.
19. Инженерия и безопасность. Типы, линтеры, логи, секреты, CI, Docker.
20. Бонус: vibe coding. Короткий обновляемый блок про работу с ИИ-помощником.
21. Финальный проект и диплом.

Каждый урок: цель, 2–4 абзаца теории, примеры с запуском, 4–8 заданий, итог, документация и YouTube. Задание можно открыть по ссылке сразу. Сдавать его можно после прохождения или пропуска предшествующих тем.
